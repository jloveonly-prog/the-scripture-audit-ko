# 🗡️ SKILL-51: TYPE-AW — 행동–진술 불일치 (Deed–Word Discrepancy)

**"They profess that they know God; but in works they deny him." — Titus 1:16 KJV**

> **언제 발동하는가**: 동일 주체의 **발화**와 **행동**이 둘 다 본문에 기록되어 있을 때.
> **핵심 질문**: *"말한 것과 한 것이 같은 방향인가? 다르다면 **행동이 진실이다.**"*

---

## 1. 🎯 무기 개요

수사의 제1원칙: **진술은 조작 가능하나 행동은 흔적을 남긴다.** 말과 행동이 어긋나면 행동을 우선 채택한다.

TYPE-AW는 한 주체의 발화 기록과 행동 기록을 나란히 놓고 **방향 일치 여부**를 검사하는 무기다. 불일치가 확인되면 그 지점이 이 사건의 포렌식 핵심이 된다.

*   **분류:** 수사 포렌식 (Behavioral Forensics)
*   **Base Layer:** 수사학·행동분석 (`01_MANDATE/IDENTITY_Scribe42.md` 지식 기반)
*   **타격 목표:** 자기모순의 적발. 신학적 입장과 무관하게 성립하므로 반박 난도가 가장 낮다.

---

## 2. ⚙️ 발동 조건

```
□ 동일 주체의 발화가 본문에 기록되어 있다
□ 그 주체의 행동도 본문에 기록되어 있다
□ 둘 사이에 시간 순서를 확정할 수 있다 (DE-OVERLAP 원칙 1 적용)
□ 발화와 행동이 같은 대상·같은 사안을 향한다
```

---

## 3. 🔍 실행 단계

```
[STEP 1] 발화·행동 분리 기록
  → | 시점 | 발화(KJV) | 행동(KJV) | 구절 |
  → 시간 순서를 반드시 확정한다. "동시에"라고 명시되지 않으면 직렬 배치
    (`02_TACTICS/DEOVERLAP_Serial.md` 원칙 1).

[STEP 2] 방향 대조
  → 발화가 지시하는 방향과 행동이 실제로 향한 방향을 각각 한 문장으로 기술한다.
  → 일치 / 불일치 / 판단 불가 중 하나로 판정한다.

[STEP 3] 불일치 시 — 행동 우선 채택
  → 진술이 아니라 행동을 사실로 채택한다.
  → 🚨 단, 진술을 "거짓말"로 단정하지 않는다. 본문이 그렇게 말하지 않는 한
    확정할 수 있는 것은 "말과 행동이 어긋났다"는 사실까지다.

[STEP 4] 경쟁 설명 전수 (TYPE-E 연동)
  → 불일치를 설명하는 가설을 전부 나열한다. 최소 2개.
    통상 (a) 통제 불능·능력 한계  (b) 진술이 애초에 수단이었음  (c) 상황 변화
  → 각 가설을 본문 데이터와 대조해 기각 가능한 것을 기각한다.
  → 전부 기각되지 않으면 🟡 유력 견해가 상한이다 (IRONCLAD 불가).

[STEP 5] 판정
  → 불일치 사실 자체 : 본문 자구로 확정 가능 → EXPLICIT
  → 불일치의 원인    : 본문이 동기를 서술하지 않으면 확정 불가 → 유력 견해 이하
```

## 4. 📌 레퍼런스 케이스 A: 거라사 군단 (막 5:12-13)

```
[STEP 1] 발화·행동 분리

  | 시점 | 발화                                  | 행동                          | 구절     |
  |------|---------------------------------------|-------------------------------|----------|
  | T1   | "Send us into the swine, that we may  |                               | 막 5:12  |
  |      |  enter into them" (숙주를 달라)        |                               |          |
  | T2   |                                       | 돼지 떼에 들어감              | 막 5:13  |
  | T3   |                                       | 약 2,000두가 즉시 익사        | 막 5:13  |

[STEP 2] 방향 대조
  발화 방향 : 숙주 확보 (거처를 원함)
  행동 방향 : 숙주 전량 즉시 파괴
  → 💥 불일치

[STEP 3] 행동 우선
  → "숙주 확보"가 최종 목적이었다는 진술은 행동과 어긋난다.

[STEP 4] 경쟁 설명 전수
  (a) 통제 불능 — 군단 규모가 돼지 떼를 감당하지 못함
  (b) 파괴가 목적 — 숙주는 수단이었음
  (c) 상황 변화 — 입주 후 예기치 못한 요인 발생 (본문 근거 없음 → 기각)

  → (a)와 (b) 모두 본문 내부 모순으로 죽지 않는다.
  → TYPE-AX(Cui Bono)를 연계 발동해 결과 정합성을 비교한다.

[STEP 5] 판정
  불일치 사실   : ✅ EXPLICIT (막 5:12와 5:13이 한 문단 안에 연속 기록)
  불일치의 원인 : 🟡 유력 견해 상한 — 본문이 동기를 서술하지 않음
```

## 📌 레퍼런스 케이스 B: 베드로의 부인 (마 26:35 → 26:69-75)

```
  발화 T1 : "Though I should die with thee, yet will I not deny thee" (마 26:35)
  행동 T2 : 세 차례 부인 (마 26:70, 72, 74)
  → 💥 불일치. 그리고 이 경우 본문이 원인을 스스로 밝힌다 —
     예수님의 예고(마 26:34)가 선행하므로 (c) 상황 변화가 아니라
     화자의 자기 인식 오류임이 본문에 의해 확정된다.
  → 판정: ✅ EXPLICIT (불일치 + 원인 모두 본문 명시)

  ⚠️ 케이스 A와의 차이: A는 본문이 동기를 침묵하고, B는 본문이 동기를 말한다.
     같은 무기라도 본문이 말해주는 만큼만 확정한다.
```

## 5. ⚠️ 혼동 금지

| 무기 | 무엇을 보는가 |
|:---:|:---|
| **TYPE-AW** (본 무기) | 동일 주체의 **말 vs 행동** |
| `TYPE-AV` (진술 분석) | 말한 내용 **안에서** 자발/비자발 구분 |
| `TYPE-AC` (역가설 검증) | ¬A를 대입해 **텍스트 간** 모순 적발 |
| `TYPE-AI` (귀류법) | 상대 가설을 대입해 **논리적** 모순 폭발 |
| `TYPE-AN` (움직이는 골대) | 상대가 **기준 자체를 이동**시키는 것 |

> TYPE-AW는 **한 주체 내부**의 말↔행동 어긋남만 본다. 두 문서·두 진술 사이의 충돌은 TYPE-AC다.

## 6. 🔗 연계 TYPE

```
TYPE-AW (행동–진술 불일치)
    ├─ 불일치 원인 후보 비교 → TYPE-AX (Cui Bono 역산)
    ├─ 경쟁 가설 전수 기각   → TYPE-E (경쟁 모델)
    ├─ 가장 단순한 설명 채택 → TYPE-AK (오컴의 면도날)
    └─ 발화 내부 분석 선행   → TYPE-AV (진술 분석)
```

## 7. 🚧 남용 방지

```
□ "거짓말했다"고 단정하지 않는다. 확정 가능한 것은 "어긋났다"까지다.
□ 발화와 행동의 시간 순서를 먼저 확정한다 — 순서가 불명확하면 이 무기를 쓰지 않는다.
□ 불일치의 원인은 본문이 말하지 않으면 유력 견해가 상한이다.
```
