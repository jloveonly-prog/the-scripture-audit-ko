# 🗡️ SKILL-52: TYPE-AX — 결과 수익자 역산 (Cui Bono)

**"Wherefore by their fruits ye shall know them." — Matthew 7:20 KJV**

> **언제 발동하는가**: 사건의 **결과는 본문에 기록되어 있으나 동기는 기록되지 않았을 때.**
> **핵심 질문**: *"이 사건이 실제로 만들어낸 결과는 무엇이며, **그 결과는 누구의 요구와 일치하는가?**"*

---

## 1. 🎯 무기 개요

라틴 법언 *cui bono*("누구에게 이익인가")는 동기가 불명한 사건에서 결과로부터 동기를 역산하는 수사 기법이다.

TYPE-AX는 본문에 기록된 **결과 사슬**을 끝까지 추적한 뒤, 그 최종 결과를 사건 당사자들이 **말로 표명했던 요구**와 대조한다. 결과와 요구가 정확히 맞물리면, 그것은 동기에 대한 강한 정황 증거다.

*   **분류:** 수사 포렌식 (Motive Reconstruction)
*   **Base Layer:** 수사학·범죄학 (`01_MANDATE/IDENTITY_Scribe42.md` 지식 기반)
*   **타격 목표:** 본문이 침묵하는 동기를, 본문이 기록한 결과만으로 역산

---

## 2. ⚙️ 발동 조건

```
□ 사건의 결과가 본문에 기록되어 있다
□ 사건 당사자의 동기가 본문에 서술되지 않았다
□ 당사자가 사전에 표명한 요구·의도가 본문에 기록되어 있다 (대조 대상 확보)
□ 결과에서 당사자까지 이어지는 인과 사슬이 본문 안에서 추적 가능하다
```

> ⚠️ 네 번째 조건이 핵심이다. 인과 사슬이 본문 밖으로 나가면 이 무기를 쓰지 않는다.

---

## 3. 🔍 실행 단계

```
[STEP 1] 결과 사슬 추적 — 본문 안에서만
  → 사건 직후부터 본문이 기록을 멈출 때까지 결과를 순서대로 나열한다.
  → | 단계 | 결과 | 구절 |
  → 🚨 본문에 기록되지 않은 결과를 추론으로 추가하지 않는다.

[STEP 2] 최종 결과 확정
  → 사슬의 마지막 항을 한 문장으로 특정한다.

[STEP 3] 표명된 요구 목록화
  → 당사자가 사건 이전에 말로 표명한 요구를 전부 수집한다.
  → TYPE-AV(진술 분석) / TYPE-AY(요구 계층 분석)의 산출물을 그대로 받는다.

[STEP 4] 대조
  → 최종 결과 ↔ 표명된 요구를 1:1 대조한다.
  → 일치 / 부분 일치 / 무관 / 상반 중 하나로 판정한다.

[STEP 5] 경쟁 수익자 검사 (필수 — 생략 금지)
  → "이 결과로 이익을 본 다른 주체는 없는가?"를 반드시 묻는다.
  → 후보를 전부 나열하고 각각 대조한다.
  → 유일 수익자가 아니면 정황 강도를 하향한다.

[STEP 6] 판정
  → 결과 사슬 자체        : 본문 자구 → EXPLICIT
  → 결과와 요구의 일치     : 대조 결과 → EXPLICIT
  → "그러므로 그것이 동기였다" : 본문이 동기를 말하지 않으면 🟡 유력 견해가 상한
```

---

## 4. 📌 레퍼런스 케이스: 거라사 돼지 떼 (막 5:10-18)

```
[STEP 1~2] 결과 사슬 추적

  | 단계 | 결과                                          | 구절    |
  |------|-----------------------------------------------|---------|
  | ①    | 돼지 약 2,000두 익사                           | 막 5:13 |
  | ②    | 치던 자들이 도망하여 성읍과 시골에 알림          | 막 5:14 |
  | ③    | 사람들이 나아와 보고 두려워함                    | 막 5:15 |
  | ④    | 그 지방에서 떠나시기를 간청함                    | 막 5:17 |
  | ⑤    | 예수님이 배에 오르심 (실제 떠나심)               | 막 5:18 |

  최종 결과: 예수님이 그 지방을 떠나셨다.

[STEP 3] 표명된 요구 (TYPE-AV 산출물 수령)
  요구 ①: 고통을 주지 마소서                     (막 5:7 / 마 8:29)
  요구 ②: 이 지방에서 내보내지 마소서              (막 5:10)  ← 지역 관련
  요구 ③: 무저갱으로 보내지 마소서                 (눅 8:31)
  요구 ④: 저 돼지들에게 보내소서                   (막 5:12)

[STEP 4] 대조
  최종 결과(예수님이 지방을 떠나심) ↔ 요구 ②(우리를 지방에서 내보내지 마소서)
  → 두 주체 중 실제로 그 지방을 떠난 것은 마귀가 아니라 예수님이다.
  → 판정: **요구 ②와 정합** (요구자는 잔류, 축출된 것은 상대편)

[STEP 5] 경쟁 수익자 검사
  · 돼지 주인/치던 자 → 경제적 손실. 수익 없음 ❌
  · 성읍 주민        → 두려움에 빠짐. 수익 없음 ❌
  · 고침받은 사람    → 온전해짐(막 5:15). 그러나 돼지 파괴로 얻은 것이 아님 ❌
  · 군단             → 지역 잔류 + 축출 위협 제거 ✅ **유일 수익자**

[STEP 6] 판정
  결과 사슬            : ✅ EXPLICIT (막 5:13→14→15→17→18 연속 기록)
  결과와 요구②의 일치   : ✅ EXPLICIT
  유일 수익자           : ✅ STRONG (경쟁 후보 3건 전부 기각)
  "파괴가 동기였다"      : 🟡 유력 견해 — 본문이 동기를 서술하지 않으며,
                          TYPE-AW 경쟁 가설 (a)통제 불능이 내부 모순으로 죽지 않음

  ⚠️ 정직 고지: 이 무기가 확정하는 것은 "결과가 요구②와 일치하고 군단이 유일
     수익자"라는 데까지다. 그것을 "따라서 처음부터 계획된 파괴"로 승격하려면
     본문의 동기 서술이 필요하며, 그것이 없다.
```

---

## 5. ⚠️ 혼동 금지

| 무기 | 무엇을 보는가 |
|:---:|:---|
| **TYPE-AX** (본 무기) | **결과 → 동기** 역산. 누가 이익을 봤는가 |
| `TYPE-AD` (귀추법) | 최선의 설명 추론 일반. **결과 수익자에 국한되지 않음** |
| `TYPE-AW` (행동–진술 불일치) | 말과 행동의 **어긋남 자체** |
| `TYPE-O` (물리적 흔적) | 사건이 남겼어야 할 **물리적 증거의 유무** |
| `TYPE-L` (연쇄 추론) | 앵커를 지렛대로 한 **논리 체인 구성** |

> TYPE-AD가 "가장 그럴듯한 설명"을 찾는다면, TYPE-AX는 **"결과의 수혜 구조"**라는 특정 렌즈 하나만 쓴다.

## 6. 🔗 연계 TYPE

```
TYPE-AX (Cui Bono 역산)
    ├─ 요구 목록 수령      → TYPE-AV / TYPE-AY
    ├─ 불일치 원인 판별    → TYPE-AW (행동–진술 불일치)
    ├─ 경쟁 수익자 전수 기각 → TYPE-E (경쟁 모델)
    └─ 체인 완성           → TYPE-L (연쇄 추론)
```

## 7. 🚧 남용 방지

```
□ 결과 사슬은 반드시 본문 안에서만 추적한다. 본문이 기록을 멈춘 곳에서 멈춘다.
□ STEP 5(경쟁 수익자 검사)를 절대 생략하지 않는다.
  → 생략하면 "내가 지목하고 싶은 자가 수익자"라는 확증 편향이 그대로 통과한다.
□ 동기 확정은 본문의 명시적 서술이 있을 때만 가능하다.
  → 없으면 🟡 유력 견해가 상한 (`02_TACTICS/ANCHOR_ThirdData.md` STEP 4-P ③).
□ "이익을 봤으므로 계획했다"는 추론은 논리적 비약이다 — 결과 정합성과 사전 의도는
  별개 명제이며, 후자는 별도 증거를 요구한다.
```
