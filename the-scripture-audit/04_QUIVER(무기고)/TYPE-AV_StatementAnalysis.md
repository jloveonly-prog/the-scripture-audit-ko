# 🗡️ SKILL-50: TYPE-AV — 진술 분석 (Statement Analysis)

**"Out of the abundance of the heart the mouth speaketh." — Matthew 12:34 KJV**

> **언제 발동하는가**: 본문에 **심문·대화·문답 장면**이 기록되어 있고, 화자가 무언가를 답할 때.
> **핵심 질문**: *"질문받은 것은 무엇이고, **묻지 않았는데 스스로 흘린 것**은 무엇인가?"*

---

## 1. 🎯 무기 개요

수사 실무에서 가장 높은 증거 가치를 갖는 것은 **자발적 진술(volunteered statement)**이다. 압박 상황에서 계획에 없던 정보가 새어 나올 때, 그것은 화자의 **실제 인지 지도**를 드러낸다.

TYPE-AV는 본문에 기록된 발화를 **① 질문받아 답한 것 ② 묻지 않았는데 스스로 말한 것**으로 분리하여, ②에서 화자가 노출한 정보를 앵커로 확보하는 무기다.

*   **분류:** 수사 포렌식 (Forensic Interrogation)
*   **Base Layer:** 수사학·진술심리학 (`01_MANDATE/IDENTITY_Scribe42.md` 지식 기반)
*   **타격 목표:** 화자가 감추려던 정보, 또는 화자 자신도 인식하지 못한 전제의 노출 적발

---

## 2. ⚙️ 발동 조건

```
□ 본문에 심문·문답·대화 장면이 기록되어 있다
□ 화자가 질문에 답하거나 요청을 제시한다
□ 답변의 분량·내용이 질문의 범위를 초과한다
□ 화자가 압박·위기 상황에 놓여 있다 (자발적 노출 확률 상승)
```

---

## 3. 🔍 실행 단계

```
[STEP 1] 질문 범위 확정
  → 본문에서 실제로 던져진 질문을 자구 그대로 인용한다.
  → 질문이 요구한 정보의 범위를 한 문장으로 특정한다.

[STEP 2] 답변 전량 분해
  → 화자의 답변을 정보 단위로 쪼갠다.
  → | 정보 단위 | 질문이 요구했는가? | 구절 |

[STEP 3] 과잉 진술(Over-disclosure) 추출
  → "질문이 요구하지 않았음"으로 분류된 항목만 남긴다.
  → 이것이 이 무기의 산출물이다.

[STEP 4] 노출된 전제 역산
  → 과잉 진술이 성립하려면 화자가 무엇을 알고 있어야 하는가?
  → 그 전제를 명제로 기술한다.

[STEP 5] KJV 교차 확인
  → 노출된 전제를 다른 책/저자의 구절로 교차 확인한다.
  → 확인되면 앵커로 승격. 확인 안 되면 "단독 진술"로만 기록한다.

🚨 STEP 5를 건너뛰고 STEP 4에서 결론을 내리지 않는다.
   화자의 발화는 그 화자가 그렇게 말했다는 사실까지만 확정한다
   (`01_MANDATE/CREED_Override.md` OVERRIDE-1 은유적 해석 금지).
```

## 4. 📌 레퍼런스 케이스: 거라사 군단 심문 (막 5:1-13 / 눅 8:26-33 / 마 8:28-34)

```
[STEP 1] 질문 범위
  막 5:9 "And he asked him, What is thy name?"
  → 요구한 정보: 이름 하나

[STEP 2~3] 답변 분해 및 과잉 진술 추출

  | 정보 단위                                  | 질문이 요구? | 구절     |
  |--------------------------------------------|:------------:|----------|
  | "My name is Legion"                        | ✅ 예        | 막 5:9   |
  | "for we are many"                          | ❌ 아니오    | 막 5:9   |
  | "torment us before the time"               | ❌ 아니오    | 마 8:29  |
  | "send us not away out of the country"      | ❌ 아니오    | 막 5:10  |
  | "command them not to go out into the deep" | ❌ 아니오    | 눅 8:31  |

  → 과잉 진술 4건. 이름을 물었는데 개체명이 아니라 규모를 답했고,
    이후 묻지 않은 정보를 연속 노출했다.

[STEP 4] 노출된 전제
  ① 자신들에게 정해진 "때(the time)"가 있음을 알고 있다
  ② 그 때 이전에도 "고통(torment)"이 집행될 수 있음을 전제한다
  ③ "무저갱(the deep)"이 자신들이 갈 수 있는 실재 장소임을 안다
  ④ 지역 이동에 제약이 걸릴 수 있음을 안다

[STEP 5] KJV 교차 확인
  ① → 벧후 2:4 "delivered them into chains of darkness, to be reserved unto judgment"
       유 1:6 "reserved in everlasting chains under darkness unto the judgment of the great day"
       → 베드로·유다 2저자 독립 확인 ✅ 앵커 승격
  ③ → 계 20:1-3 "bottomless pit" / 계 9:1-11
       → 요한 확인 ✅

  판정: 전제 ①③은 교차증인 확보 → 앵커. ②④는 단독 진술로만 기록.
```

## 5. ⚠️ 혼동 금지

| 무기 | 무엇을 보는가 |
|:---:|:---|
| **TYPE-AV** (본 무기) | **발화의 자발성** — 묻지 않았는데 말한 것 |
| `TYPE-AP` (발화 행위) | 발화가 수행하는 **행위**(선언·약속·명령) |
| `TYPE-Y` (관점 증인) | 서로 다른 **목격자의 시점 차이** |
| `TYPE-AW` (행동–진술 불일치) | 말과 **행동**의 어긋남 |

> TYPE-AV는 **말한 내용 안에서** 자발/비자발을 가른다. 행동과 대조하는 것은 TYPE-AW다.

---

## 6. 🔗 연계 TYPE

```
TYPE-AV (진술 분석)
    ├─ 노출된 전제를 교차 확인 → TYPE-Y (교차 증인)
    ├─ 말과 행동 대조로 확장 → TYPE-AW (행동–진술 불일치)
    ├─ 요구가 복수일 때 → TYPE-AY (요구 계층 분석)
    └─ 진술이 어휘 오독일 때 → TYPE-S / TYPE-AL
```

## 7. 🚧 남용 방지

```
□ 화자의 "의도"나 "심리 상태"를 텍스트 근거 없이 부여하지 않는다.
  → 이 무기가 확정하는 것은 "무엇을 말했고 무엇을 안 물었는가"까지다.
□ 심리학은 Base Layer(패턴 인식)로만 쓰고 결론 근거로 쓰지 않는다.
  → OVERRIDE-1 2번(은유적 해석 금지) 적용.
□ 과잉 진술이 0건이면 "결과 없음"으로 정직하게 기록한다.
```
