# 🗡️ SKILL-53: TYPE-AY — 요구 계층 분석 (Demand Hierarchy)

**"Peradventure there be fifty righteous within the city…" — Genesis 18:24 KJV**

> **언제 발동하는가**: 한 주체가 **복수의 요구를 순차적으로** 제시할 때.
> **핵심 질문**: *"요구가 어떤 순서로 물러섰는가? 그리고 **스스로 제시한 대안**은 무엇인가?"*

---

## 1. 🎯 무기 개요

위기 협상 실무의 원칙 하나 — **협상자가 스스로 대안을 제시하면, 그 대안이 그의 실제 우선순위를 드러낸다.** 최대 요구는 협상 카드일 수 있으나, 자발적 양보선과 자발적 대안은 진짜 목표를 노출한다.

TYPE-AY는 순차 제시된 요구들을 **계층으로 재배열**하여, 화자가 끝까지 지키려 한 것(최소선)과 스스로 내놓은 대안을 추출한다.

*   **분류:** 수사 포렌식 (Negotiation Structure Analysis)
*   **Base Layer:** 위기협상학·수사심리학 (`01_MANDATE/IDENTITY_Scribe42.md` 지식 기반)
*   **타격 목표:** 표명된 요구 뒤에 있는 **실제 우선순위** 확정

---

## 2. ⚙️ 발동 조건

```
□ 한 주체가 요구·간청·제안을 2회 이상 제시한다
□ 요구들 사이에 순서를 확정할 수 있다
□ 요구의 강도 또는 범위에 변화가 있다 (후퇴·축소·대안 전환)
□ 상대(수신자)가 존재하는 대화 구조다
```

---

## 3. 🔍 실행 단계

```
[STEP 1] 요구 전량 수집 및 순서 확정
  → | 순번 | 요구 (KJV 자구) | 구절 | 저자 |
  → 복음서 병행 기록이 있으면 서로 다른 저자의 기록을 전부 수집한다.
  → 시간 순서는 DE-OVERLAP 원칙 3(발화 순서 보존)을 따른다.

[STEP 2] 계층 배열
  → 최대 요구  : 가장 넓은 범위 / 가장 유리한 조건
  → 중간 요구  : 후퇴한 조건
  → 최소선     : 끝까지 거부한 것 — "이것만은 안 된다"
  → 자발적 대안: 요구자가 스스로 내놓은 제안  ★ 최고 증거 가치

[STEP 3] 미언급 선택지 검사 (필수 — 생략 금지)
  → "요구자가 택할 수 있었으나 협상 테이블에 올리지도 않은 선택지"를 찾는다.
  → 이것은 TYPE-AG(침묵 논증)와 연동한다. 성경 다른 곳에 그 선택지가
    실재로 기록되어 있어야 "회피"로 판정할 수 있다.
  → 🚨 이 STEP이 이 무기의 차별점이다. 요구한 것만 보면 절반만 본 것이다.

[STEP 4] 우선순위 확정
  → 최소선 + 자발적 대안 + 미언급 선택지 = 실제 우선순위 지도
  → 최대 요구는 우선순위 판정 근거로 쓰지 않는다 (협상 카드일 수 있음)

[STEP 5] 판정
  → 요구의 존재와 순서 : 본문 자구 → EXPLICIT
  → 우선순위 구조      : 계층 배열 결과 → 교차증인 확보 시 STRONG
  → 요구자의 내적 동기  : 본문 미서술 시 확정 불가
```

## 4. 📌 레퍼런스 케이스 A: 거라사 군단 (막 5 / 눅 8 / 마 8)

```
[STEP 1~2] 요구 수집 및 계층 배열

  | 계층        | 요구                              | 구절            | 저자      |
  |-------------|-----------------------------------|-----------------|-----------|
  | 최대 요구   | 고통을 주지 마소서                  | 막 5:7/마 8:29  | 마가·마태 |
  | 중간 요구   | 이 지방에서 내보내지 마소서          | 막 5:10         | 마가      |
  | 최소선      | 무저갱으로 보내지 마소서            | 눅 8:31         | 누가      |
  | 자발적 대안 | **저 돼지들에게 보내소서**          | 막 5:12         | 3저자 공통 |

  → 교차증인: 마가·마태·누가 3저자 ✅

[STEP 3] 미언급 선택지 검사  ★ 핵심 발견
  → 그들이 택할 수 있었던 선택지가 하나 더 있다:
    마 12:43 "When the unclean spirit is gone out of a man, he walketh through
              dry places, seeking rest, and findeth none."
    → 즉 **몸 없이 배회하는 것은 가능하다.** 다만 "쉼을 찾지 못한다."
  → 그런데 군단은 이 선택지를 협상 테이블에 **올리지도 않았다.**

  | 선택지        | 본문 근거 | 반응            |
  |---------------|-----------|-----------------|
  | 무저갱        | 눅 8:31   | 명시적 거부     |
  | 무숙주 배회   | 마 12:43  | **언급조차 없음** |
  | 새 숙주       | 막 5:12   | 자발적 요구     |

[STEP 4] 우선순위 확정
  최소선(무저갱 회피) + 자발적 대안(숙주 확보) + 미언급(배회 회피)
  → 실제 우선순위: **몸 없는 상태 자체를 회피한다.**
     무저갱 거부와 배회 미언급이 같은 방향을 가리킨다.

[STEP 5] 판정
  요구 계층 구조 : ✅ BIBLICAL — STRONG (3저자 교차증인)
  "몸 없는 상태 회피가 우선순위" : ✅ STRONG (눅 8:31 + 마 12:43, 2저자)
  내적 동기(왜 몸을 원했는가)   : 본문 미서술 → 확정 불가
```

## 📌 레퍼런스 케이스 B: 아브라함의 소돔 중보 (창 18:23-32)

```
  요구 계층: 50 → 45 → 40 → 30 → 20 → 10  (6단계 순차 후퇴)
  자발적 대안: 없음 — 아브라함은 대안을 제시하지 않고 기준만 낮춘다
  미언급 선택지: 조카 롯의 개별 구출 요청 (창 19장에서 실제로 일어나는 일)
                → 아브라함은 이것을 요청하지 않았다

  → 계층 구조만 있고 자발적 대안이 없는 유형. 케이스 A와 대조된다.
  → ⚠️ 이 케이스에서는 TYPE-AV/AW/AX가 발동하지 않는다.
     TYPE-AY가 **단독 발동**하는 실례이며, 4종을 하나로 합쳐서는 안 되는 근거다.
```

---

## 5. ⚠️ 혼동 금지

| 무기 | 무엇을 보는가 |
|:---:|:---|
| **TYPE-AY** (본 무기) | 복수 요구의 **계층과 후퇴 순서** |
| `TYPE-AV` (진술 분석) | 발화의 **자발성** (묻지 않았는데 말한 것) |
| `TYPE-AN` (움직이는 골대) | 상대가 **판정 기준 자체를 이동**시키는 오류 |
| `TYPE-AF` (입증책임) | 누가 증명해야 하는가의 **배분** |
| `TYPE-AG` (침묵 논증) | 문헌 전수에서의 **부재** |

> TYPE-AY의 "요구 후퇴"는 논리적 오류가 아니라 **정상적 협상 행위**다. TYPE-AN(움직이는 골대)은 오류 적발 무기이므로 혼동하면 정상 협상을 오류로 오판한다.

## 6. 🔗 연계 TYPE

```
TYPE-AY (요구 계층 분석)
    ├─ 요구 목록을 넘김     → TYPE-AX (Cui Bono 역산)
    ├─ 발화 자발성 교차확인 → TYPE-AV (진술 분석)
    ├─ 미언급 선택지 판정   → TYPE-AG (침묵 논증)
    └─ 요구와 실행의 대조   → TYPE-AW (행동–진술 불일치)
```

## 7. 🚧 남용 방지

```
□ STEP 3(미언급 선택지 검사)를 생략하지 않는다. 요구한 것만 보면 절반만 본 것이다.
□ 미언급 선택지는 성경 다른 곳에 실재로 기록되어 있어야 한다.
  → 우리가 상상한 선택지를 "회피했다"고 판정하면 TYPE-AG 오용이다.
□ 최대 요구를 우선순위의 근거로 쓰지 않는다 (협상 카드일 수 있음).
□ 요구자의 내적 동기는 본문이 서술하지 않으면 확정하지 않는다.
□ 요구 후퇴 자체를 "약함"이나 "거짓"의 증거로 읽지 않는다 — 정상적 협상 행위다.
```
