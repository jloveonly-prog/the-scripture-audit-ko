# ITC-LIMBO-2007 — 세례 없이 죽은 유아의 구원 희망 (림보 교리의 사실상 폐기)

| 항목 | 내용 |
|:---|:---|
| **ID** | ITC-LIMBO-2007 |
| **출처** | 국제신학위원회 (International Theological Commission), 「세례 없이 죽은 유아의 구원 희망」 |
| **조항** | 결론부 (교황 베네딕토 16세 공표 승인, 2007-04-19) |
| **교의 등급** | Pastoral (자문 기관 문서 — 교도권 정의 아님) |
| **무류 여부** | 🟢 사목적 (구속력 없음 — ITC는 신앙교리성 자문 기구) |
| **파문(Anathema)** | 아니오 |
| **연도** | 2007 |

## 원문 (요약)
> "세례 없이 죽은 유아가 구원받아 영원한 행복에 이르리라고 **희망할 신학적·전례적 근거가 있다**. 다만 계시 안에 이 문제에 관한 명시적 가르침이 있는 것은 아니다."
> 림보에 관하여: "림보 이론은 **교도권의 교의적 정의에 결코 들어간 적이 없다**. 비록 같은 교도권이 통상적 가르침에서 때때로 그 이론을 언급하기는 했지만." — "따라서 그것은 **가능한 신학적 가설로 남는다**." 또한 비오 6세의 칙서 `Auctorem fidei`도 림보의 존재에 대한 교의적 정의가 아니다.

## 태그
`구원론`, `세례`, `유아세례`, `림보`, `목표대이동`, `사목적`

## 주장 (Claims)
1. 세례 없이 죽은 유아의 구원을 희망할 신학적·전례적 근거가 있다
2. 림보 이론은 교도권의 교의적 정의에 들어간 적이 없다
3. 림보는 확정 교리가 아니라 가능한 신학적 가설에 불과하다
4. 교도권이 통상적 가르침에서 림보를 언급한 적은 있음을 인정한다
5. 계시 안에 이 문제에 관한 명시적 가르침은 없다

## 부정 (Negates)
1. 세례 없이 죽은 유아는 반드시 림보에 머문다는 명제
2. 림보가 교회의 확정된 교의라는 명제
3. 세례 없이 죽은 유아의 구원을 희망하는 것이 교리에 어긋난다는 명제

## 관련 충돌
- → CCC-1250 (유아도 원죄 해방을 위해 세례 필요)
- → CCC-1257 (교회는 세례 외에 영원한 행복에 이르는 다른 수단을 알지 못함)
- → CCC-1261 (같은 방향 — 구원 희망 인정)
