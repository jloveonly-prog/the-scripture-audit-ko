# 📋 01_CLAIMS(주장추출)

> **GATE -1에서 추출된 교리 주장 목록이 저장되는 폴더입니다.**

## 파일 구조

각 설교마다 하나의 클레임 목록 파일이 생성됩니다.

- 파일명 규칙: `CLAIMS_[설교자명]_[설교제목]_[날짜].md`
- 예: `CLAIMS_홍길동_골로새서강해_20260628.md`

## 내용 구성

```
| # | 시간대 | 주장 요약 (의역) | 인용 구절 | 위험도 | BVCAP 투입 여부 |
```

- **주장 요약**: 설교자의 원문이 아닌, AI가 의역한 내용으로 기록 (저작권 보호)
- **위험도**: 🟢 안전 / 🟡 검증 필요 / 🔴 즉시 검증
- **BVCAP 투입 여부**: 해당 주장이 GATE 0~5로 투입되었는지 여부
